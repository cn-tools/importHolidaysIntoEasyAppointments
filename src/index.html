Import Holidays into EasyAppointments

1 - Welcome

This tool allows you to import holidays with data from OpenHolidaysAPI into EasyAppointments.

Import automatically public holidays directly into your EasyAppointments installation in seconds. No more manually creating holidays - simply select the country, enter your API credentials, and import.

You will be guided through the process step by step.

Your data stays under your control:
All communication happens directly between your browser and your EasyAppointments instance. No third-party services, proxy servers, or intermediate systems are involved, and no credentials or holiday data are stored or processed on external servers.

Getting Started

  • Review and accept the Terms of Use
  • Enter your EasyAppointments URL and API Bearer Token
  • Select the country whose public holidays you want to import
  • Choose the subdivision/region and preferred language
  • Define the date range for the holiday search
  • Load the holidays, review the results, select the entries to import, and start the import
