Import Holidays into EasyAppointments

1 - Welcome

This tool allows you to import holidays from OpenHolidaysAPI into EasyAppointments.

Steps:

  1. Choose country
  2. Choose subdivision and language
  3. Select date range
  4. Provide EasyAppointments URL and API Bearer key
  5. Load, review and select holidays and import

2 - Country

Choose your country of origin

3 - Subdivision & Language

Choose your subdivision and language

4 — Date range

Times are set to 00:01 (from) and 23:59 (to) automatically.

5 — Destination (EasyAppointments)

The API Bearer Key is not sent to any server or third-party service. It is used locally in your browser to get and post data to the provided EasyAppointments instance.

6 — Preview & Import

Click the button to load the public holidays preview
