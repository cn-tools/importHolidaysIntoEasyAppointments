Import Holidays into Easy!Appointments

1 - Welcome

This tool allows you to import holidays with data from OpenHolidaysAPI into Easy!Appointments.

Import automatically public holidays directly into your Easy!Appointments installation in seconds. No more manually creating holidays - simply select the country, enter your API credentials, and import.

You will be guided through the process step by step.

Your data stays under your control:
All communication happens directly between your browser and your Easy!Appointments instance. No third-party services, proxy servers, or intermediate systems are involved, and no credentials or holiday data are stored or processed on external servers.

Getting Started

  • Review and accept the Terms of Use
  • Enter your Easy!Appointments URL and API Bearer Token
  • Select the country whose public holidays you want to import
  • Choose the subdivision/region and preferred language
  • Define the date range for the holiday search
  • Load the holidays, review the results, select the entries to import, and start the import

3 — Destination (Easy!Appointments)

To establish the connection, please enter the URL and API Key in the corresponding fields. Once both values have been provided, click "Test Connection" to verify that the connection can be established successfully.

If the test is successful, the system will confirm that the configuration is valid and ready for use. If the connection test fails, please review the entered URL and API Key and try again.

Notice: The API Bearer Key is not sent to any server or third-party service. It is used locally in your browser to get and post data to the provided Easy!Appointments instance.

7 — Preview & Import

Click "Load Public Holidays" to display all available public holidays. Once the list is loaded, you can review the holidays and select which ones should be imported into Easy!Appointments.
