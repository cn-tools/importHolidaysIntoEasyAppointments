# Security Policy

## Supported Versions

The following versions of this project are currently supported with security updates.

| Version | Supported |
|---------|-----------|
| Latest release | ✅ |
| Previous major release | ❌ |
| Older releases | ❌ |

If you are using an unsupported version, please upgrade to a supported release before reporting issues.

## Reporting a Vulnerability

We take the security of this project seriously and appreciate responsible disclosure of vulnerabilities.

### How to Report

Please do **not** report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Instead, report vulnerabilities by:

- Creating a private security report through GitHub's **Security Advisories** feature, if enabled.
- Contacting the maintainers via: **cn-tools@gmx.at**
- Alternatively, open a confidential report through your organization's designated security channel.

### Information to Include

To help us assess and resolve the issue as quickly as possible, please provide:

- A detailed description of the vulnerability
- Steps to reproduce the issue
- A proof of concept (PoC), if available
- The affected version(s)
- Potential impact and attack scenarios
- Any suggested mitigations or fixes

### What to Expect

After receiving your report, we will:

1. Acknowledge receipt within **5 business days**.
2. Assess and validate the vulnerability.
3. Provide status updates during the investigation.
4. Work on a fix and coordinate responsible disclosure.
5. Publish security advisories when appropriate.

### Disclosure Policy

We kindly ask that you:

- Allow reasonable time for investigation and remediation before public disclosure.
- Avoid accessing, modifying, or deleting data that does not belong to you.
- Act in good faith to avoid privacy violations, service disruption, or data destruction.

### Scope

This policy applies to:

- Source code contained in this repository
- Official releases and distribution packages
- Project-maintained infrastructure directly related to the repository

Third-party dependencies are covered by their respective maintainers' security policies.

## Security Updates

Security fixes will be released as soon as practical. Critical vulnerabilities may result in out-of-band releases.

We appreciate the efforts of security researchers and the community in helping keep this project secure.
